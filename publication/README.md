# VariFuse numerical evidence

This directory contains compact numerical records and four reproducible figures
for the completed missense-variant comparison. The manuscript and author contact
files are kept in the author's local submission package, outside the public code
release.

The original experiment and later controls are different evidence phases. All
later controls, clinical rescoring and paired intervals are exploratory because
the original outcomes and clinical cohort had already been inspected. No claim
of untouched external confirmation, clinical utility or state-of-the-art
superiority is made.

## Recreate the figures

From the repository root with the research dependencies installed:

```powershell
python tools/verify_manuscript_evidence.py
python tools/build_manuscript_figures.py
```

The figure builder reads the compact full-precision metric files. It writes PNG
and SVG outputs under `publication/figures`. This operation does not recreate
fitted model predictions. Figures 1 and 2 are programmatic explanatory diagrams;
Figures 3 and 4 visualize recorded results. Plotting and analysis code was
prepared with assistance from OpenAI Codex using GPT-6; no experimental
observations were synthesized.

## Recreate the analyses from fitted artifacts

With the original local pipeline artifacts and all 40 control checkpoints:

```powershell
python tools/summarize_research_controls.py
python tools/analyze_manuscript_controls.py --bootstrap 1000
python tools/collect_manuscript_evidence.py
```

The summary utility verifies checkpoint hashes and converts only legacy
object-string identity arrays. The analysis utility validates source/code hashes,
aligns clinical variant identities and labels, scores each saved fold using its
own preprocessing, and retains the strict-majority frozen-threshold decision
rule. It does not fit or change an original model. Later summaries do not
replace original nested out-of-fold evidence.

The collector also expects the author's dated original-run audit at
`audit_reports/readiness_20261004/verified_evidence.json`. That local audit source
is not generated by training and is not distributed as a runnable dependency.
Its checksummed numerical record is distributed as
`evidence/original_verified_evidence.json`; verification and figure recreation
from the public compact package do not require the private audit directory.

The compact split summary excludes row-index lists; the original full split plan
is authenticated by its checksum. Large trained weights, embeddings and upstream
databases are not distributed in this Git repository. Reproducing those artifacts
requires the pinned source data and full pipeline documented in the root README,
DATA_SOURCES.md and REPRODUCIBILITY.md. The original Linux/T4 and later Windows
environments are recorded separately; cross-environment bitwise identity is not
promised.

`.gitattributes` disables Git newline conversion because protocol and evidence
checksums authenticate raw file bytes. Preserve these bytes when moving the
code or compact records between operating systems.

## Records

- `evidence/original_verified_evidence.json` records the historical original-run
  audit. Its old control-status fields are superseded by the newer control files.
- `evidence/control_metrics.json` contains all eight controls' complete internal
  and clinical metrics.
- `evidence/control_*_intervals.json` contains fixed-prediction paired intervals;
  internal clusters are connected split groups and clinical clusters are genes.
- `evidence/original_selection_recipes.json` and `split_summary.json` retain
  feature order, search spaces, selected recipes, counts and seed provenance.
- `evidence/dms_aggregation.json` separates assay-macro and protein/category
  summaries on the retained ProteinGym subset.
- `evidence/functional_model_metrics.csv` reports all models on the selected
  19-variant HMGCR sensitivity set, including negative correlations.
- `evidence/evidence_manifest.json` binds the compact records to source and
  output SHA256 values.
- `evidence/selected_20_references.json` contains bibliographic identities for
  the targeted journal-fit reading set, without abstracts or full papers. Three
  papers were examined beyond their abstracts and seventeen at abstract level.
